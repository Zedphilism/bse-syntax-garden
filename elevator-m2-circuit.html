Expressions from M1 (implement these as gate networks)

  • J2 X · Q1 · Q0 — NOT gate on X, then 3-input AND
  • K2 X · Q1 · Q0 — NOT gates on Q1 and Q0, then 3-input AND with X
  • J1 X·Q0 + X·Q2·Q0 — two AND groups feeding an OR
  • K1 X·Q0 + X·Q2·Q0 — two AND groups feeding an OR
  • J0 X + Q2 + Q1 — 3-input OR (with NOT on X)
  • K0 X + Q1 + Q2 — 3-input OR (with NOT on Q1, Q2)

Part 1 — 3-Bit JK Flip-Flop Counter

Flip-flop placement

FF2 → Q2 (most significant bit) FF1 → Q1 FF0 → Q0 (least significant bit)

Connect all three CLK pins to a single wire labelled CLK_EN. M3 drives this wire.

Inputs required

X — toggle input (0 = UP, 1 = DOWN) PRE_bar — active-low preset (tie HIGH if unused) CLR_bar — active-low clear (tie HIGH if unused)

Build order (verify incrementally)

  1. Wire J0/K0 expressions and verify FF0 toggles correctly
  2. Add FF1 with J1/K1 expressions; verify 3 lowest bits
  3. Add FF2 with J2/K2 expressions; verify full 8-state sequence
  4. Add HEX display driven by Q2 Q1 Q0
  • 3 JK flip-flops placed
  • All CLK pins connected to CLK_EN wire
  • Gate networks for all 6 expressions wired
  • HEX display added (shows current floor 0–7)
  • PRE_bar and CLR_bar tied to appropriate levels

Part 2 — 3-Bit Floor Comparator

Comparator logic
