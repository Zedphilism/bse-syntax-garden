M3 can work in parallel with M2. The three sub-circuits (card, door, passcode) are independent. You only need M2's NOT_EQUAL output when wiring the final CLK_EN AND gate.

Sub-circuit 1 — Hotel Card Detector

Design

CARD — 1-bit toggle input in DEEDS

CARD = 1 means a valid hotel card is tapped. CARD = 0 means no card / invalid card.

Wire CARD directly into the final CLK_EN AND gate. Optional: connect an LED labelled "Card OK" for visual feedback.

  • Toggle input labelled CARD added
  • LED "Card OK" connected (optional but recommended)
  • Test: CARD=0 → elevator does not move regardless of other inputs
  • Test: CARD=1 → CARD signal no longer blocks movement

Sub-circuit 2 — Door Logic

Design

DOOR_CLOSED — toggle input (1 = door is closed, safe to move) DOOR_OPEN_LED — LED connected to EQUAL signal from M2

DOOR_CLOSED feeds into CLK_EN AND gate. When M2's EQUAL goes HIGH (floor reached), DOOR_OPEN_LED lights up — this signals the door should open. The elevator cannot move again until DOOR_CLOSED returns to 1 (user closes door).

  • Toggle input labelled DOOR_CLOSED added
  • LED labelled DOOR_OPEN_LED connected to EQUAL from M2
  • Test: DOOR_CLOSED=0 → elevator does not move
  • Test: arrive at floor (EQUAL=HIGH) → DOOR_OPEN_LED lights

Sub-circuit 3 — Passcode Circuit

Chosen passcode: 1 0 1 (P2=1, P1=0, P0=1)

P2 → AND input directly (must be 1) P1 → NOT gate → AND input (must be 0, so invert) P0 → AND input directly (must be 1) 3-input AND output = PASS_OK

Change the passcode by choosing different NOT connections. Document your chosen passcode in the report.

  • Toggle inputs P2, P1, P0 added
  • NOT gate on P1 (bit that should be 0 in passcode)
  • 3-input AND gate producing PASS_OK
  • Optional: LED "Wrong code" connected to NOT(PASS_OK)
  • Test: correct code 101 → PASS_OK = 1
  • Test: wrong codes → PASS_OK = 0 (elevator blocked)

Part 4 — Final Clock Enable Integration

CLK_EN equation

CLK_EN = CLK_PUSH AND POWER AND START AND CARD AND DOOR_CLOSED AND PASS_OK AND NOT_EQUAL
CLK_PUSH — push button POWER — toggle START — toggle CARD — from sub-circuit 1 DOOR_CLOSED — from sub-circuit 2 PASS_OK — from sub-circuit 3 NOT_EQUAL — from M2's comparator
DEEDS may not have a 7-input AND gate. Use chained ANDs: e.g., group the first 4 signals into a 4-input AND, then AND that output with the remaining 3. The result is identical.
  • Push button CLK_PUSH added (replaces free-running clock)
  • Toggle inputs POWER and START added
  • All 7 signals wired into chained AND gates → CLK_EN output
  • CLK_EN output connected to M2's CLK_EN wire
  • Test: block POWER → elevator stops
  • Test: block CARD → elevator stops
  • Test: block DOOR_CLOSED → elevator stops
  • Test: wrong passcode → PASS_OK=0 → elevator stops
  • Test: EQUAL (floor reached) → NOT_EQUAL=0 → elevator stops
