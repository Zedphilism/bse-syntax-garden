This page contains all mathematical deliverables for Member 1: state diagram description, complete 16-row transition table with JK excitation values, all 6 K-maps with groups annotated, and 6 minimised Boolean expressions. Hand this to M2 before they touch DEEDS.

System Parameters

Floors 0–7 → 3-bit binary (Q2 Q1 Q0). Control input X=0 → count UP, X=1 → count DOWN. Saturated at both ends: floor 7 with X=0 stays at 7; floor 0 with X=1 stays at 0. Flip-flop type: JK (not D).

JK Excitation Rules

Q → Q⁺JK
0 → 0XX
0 → 11X
1 → 0X1
1 → 1XX

Wait — corrected: 0→0: J=0 K=X; 0→1: J=1 K=X; 1→0: J=X K=1; 1→1: J=X K=0
